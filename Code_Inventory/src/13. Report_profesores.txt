DESCRIPCIÓN TÉCNICA: report_profesores.py (Generador de Reportes por Sección)
Este script tiene como función principal la creación de reportes pedagógicos detallados en formato HTML interactivo dirigidos a los docentes de cada sección. Su objetivo es desglosar el rendimiento individual de los estudiantes y el nivel de logro alcanzado en cada indicador de aprendizaje evaluado.

1. Arquitectura y Diseño Visual
El script utiliza una estructura basada en HTML5, CSS3 y JavaScript (Chart.js). Los reportes están diseñados con un enfoque "Mobile First" y optimización para impresión física. Incluye funciones interactivas que permiten al docente reordenar las tablas de alumnos (por nombre o por puntaje) y las listas de indicadores en tiempo real dentro del navegador.

2. Énfasis en Filtros de Procesamiento y Selección de Datos
El módulo implementa filtros de limpieza y lógicas de cruce de alta complejidad para asegurar la relevancia pedagógica de la información:

* Filtro de Integración Geiser (build_master_geiser_dataframe): Une los archivos de datos biográficos (_compl) con los de puntajes (resultados) mediante un filtro de cruce interno (inner join) basado en el NIE y la Materia. Esto garantiza que no se generen reportes para alumnos sin datos académicos.

* Filtro de Detección de Ítems (Regex): Utiliza expresiones regulares para identificar y mapear automáticamente las columnas de respuestas (ej. MAT01, LEC20) específicas para cada grado y asignatura, ignorando columnas irrelevantes.

* Filtro de Observaciones de Tiempo (tiempo_inusual): Implementa un filtro de auditoría que marca con un asterisco (*) a los estudiantes que finalizaron la prueba en menos de 5 minutos o presentaron demoras extremas. Esto alerta al docente sobre posibles resultados no representativos.

* Filtro de Normalización de Nombres: Aplica una transformación de texto (str.title()) y una función de formato para unificar apellidos y nombres, eliminando espacios basura y estandarizando la visualización en las tablas.

* Filtro de Clasificación por Colores: Asigna dinámicamente clases de CSS (bg-red, bg-darkgreen, etc.) basadas en los rangos de puntaje (35, 45, 55, 65). Estos filtros visuales permiten al profesor identificar grupos de riesgo pedagógico de un vistazo.

3. Lógica de Análisis de Indicadores (Huella Dactilar)
Una de las funciones más críticas es la extracción de indicadores de logro desde el archivo maestro de ítems:

* Filtro de "Fingerprint": Para la materia de Lengua, el script genera una "huella dactilar" del texto del indicador (eliminando caracteres no alfanuméricos) para agrupar ítems que evalúan el mismo objetivo pedagógico, calculando un porcentaje de éxito combinado.

* Filtro de Nivelación: Detecta y resalta visualmente los indicadores que pertenecen a planes de nivelación académica.

* Filtro de Orden Cronológico: Permite organizar los indicadores según el "Día de Clase" sugerido en la planificación oficial, permitiendo al docente ver si el fallo ocurre en contenidos nuevos o antiguos.

4. Salida y Automatización
* Organización Jerárquica: El script crea automáticamente una carpeta para cada centro escolar (NroCentro - Nombre) y dentro de ella deposita los archivos HTML de cada grado y sección.

* Gráficos Dinámicos: Genera diagramas de "Dona" para mostrar la distribución porcentual de los niveles de desempeño de la sección y un "Sello de Promedio" con el color del nivel alcanzado por el grupo.

Resumen de Operación: Este módulo es el "analista pedagógico" del sistema; aplica filtros de integridad de tiempo, limpia identidades estudiantiles y traduce bases de datos en herramientas de diagnóstico docente listas para imprimir o distribuir digitalmente.
